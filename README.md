# WWK FAST — Cinematic Logistics Website

Кинематографичный scroll-driven сайт в стиле BR-Corio для WWK Fast Sp. z o.o.

## Стек
- Next.js 15
- React Three Fiber + Drei
- GSAP ScrollTrigger
- Lenis smooth scroll
- Tailwind CSS
- Мультиязычность (RU / EN / PL)

## Запуск

```bash
cd wwk-fast-cinematic
npm install
npm run dev
```

Открой http://localhost:3000

## Что уже есть
- Непрерывный пролёт камеры: склад → дорога → порт → контейнеровоз
- Красный + белый фирменный стиль
- Overlay-тексты появляются по скроллу
- Переключатель языков (русский по умолчанию)
- Секции: скорость/надёжность, любой груз, услуги, гарантия + CTA
